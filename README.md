# Academia de Desenho Criativo

Página estática em português. Oferta atual: material digital em PDF por R$37.

## Arquivos

- `index.html`: estrutura da página.
- `styles.css`: estilos e layout responsivo.
- `oferta.js`: textos, preço, conteúdo e link do checkout.
- `app.js`: galeria, animação, oferta, depoimentos e perguntas frequentes.
- `assets/`: imagens, animação WebP, fontes e licenças.

## Envio ao GitHub

Descompacte este pacote e envie seu conteúdo à raiz do repositório. Preserve a pasta `assets` e os nomes dos arquivos. O `index.html` deve ficar na raiz, junto com os arquivos CSS e JavaScript.

A página não precisa de instalação de dependências nem de comando de build. Pode ser publicada em hospedagem estática. As URLs dos recursos são relativas, compatíveis com publicação em subpastas.

## Checkout da Cakto

O botão permanece em INSCRIÇÕES EM BREVE porque o link do checkout ainda não foi informado.

Quando tiver a URL real, edite `oferta.js`, procure `checkoutUrl: ''` no pacote `basico` e coloque o link HTTPS entre as aspas. Publique os arquivos atualizados depois.

## Conferência

Depois de publicar, verifique a galeria, a animação, as imagens, o preço de R$37 e o destino do botão após configurar o checkout.
